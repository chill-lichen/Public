# Design directions (mockups, not live)

Two contrasting directions for the 4-page advisor site. Open `index.html` to compare them side by side.

- `a/`: stark, editorial. Black and white, red for actions, gold only as a tiny highlight.
- `b/`: warm, rounded. Warm black base, soft gold, rounded cards, tabbed service menu.
- `c/`: quiet, familiar (added after feedback). Source Serif 4 + Inter, charcoal and warm white, deep oxblood red on buttons only, low-radius cards. Same structure as A.
- `shared/menu.js`: service menu data, selection carry-over into intake, and the mock two-step intake + scheduling.

Pages are generated by `python3 build.py` (copy lives there). This folder sits outside `docs/unified`, so it is never deployed by Netlify. Intake and scheduling are mockups: nothing is sent.
